# MassaMia — Massas Artesanais

Site desenvolvido como **projeto de extensão** do curso de Análise e Desenvolvimento de Sistemas (ADS) da **UNIG**, 1º período, no tema integrador **Gestão de Carreiras** (atividade "Autoconhecimento e carreira", professor Hamilcar Silva).

🔗 **Site publicado:** https://massamiabr.bolt.host

## Parceira beneficiada

**[Denise]**, microempreendedora de [Nova Iguaçu – RJ], responsável pela **MassaMia**, negócio de massas artesanais. O site foi desenvolvido gratuitamente, a partir de entrevista de requisitos com a cliente.

## Objetivo

Dar presença digital profissional ao negócio, apresentando os produtos, facilitando o contato com novas clientes e permitindo que a própria proprietária atualize as informações da loja por meio de uma área administrativa.

## Funcionalidades

- Página inicial com apresentação do negócio
- Catálogo de produtos com fotos e preços
- Contato direto com a proprietária ([21 97144-3816])
- Área administrativa com login para atualização do conteúdo
- Layout responsivo (celular e computador)

## ODS da ONU atendidas

- **ODS 8 – Trabalho Decente e Crescimento Econômico:** apoio à digitalização de uma microempreendedora local.
- **ODS 9 – Indústria, Inovação e Infraestrutura:** uso de IA de desenvolvimento para criar uma solução acessível e robusta.
- **ODS 10 – Redução das Desigualdades:** acesso à tecnologia para quem não teria recursos para contratar um desenvolvimento profissional.

## Ferramentas utilizadas

- **Bolt.new** (IA de desenvolvimento) para gerar o front-end
- **React + TypeScript** com **Vite**
- **Tailwind CSS** para o estilo
- **Supabase** para banco de dados e autenticação
- **Git e GitHub** para versionamento
- **Bolt Hosting** para publicação

## Como executar o projeto localmente

```bash
# 1. Clone o repositório
git clone https://github.com/[usuario]/[nome-do-repositorio].git

# 2. Entre na pasta e instale as dependências
cd [nome-do-repositorio]
npm install

# 3. Crie um arquivo .env com as variáveis do Supabase
#    VITE_SUPABASE_URL=...
#    VITE_SUPABASE_ANON_KEY=...

# 4. Inicie o servidor de desenvolvimento
npm run dev
```
